
# Number Guessing Game

A simple interactive number guessing game built with Python.

## Technologies
- Python 3.13
- Docker

## Run with Docker

Build the image:

```bash
docker build -t number-guessing-game .
```

Run the game:

```bash
docker run -it --rm number-guessing-game
```

## Concepts demonstrated
- Python input and conditional logic
- Docker images and containers
- Dockerfile instructions
- Interactive container execution
